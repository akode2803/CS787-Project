Before stopping, it writes `GUARD ... STOP <reason>` to the job log and uploads the log to Drive.

It also writes a run id into the log, and it keeps the Mac awake with `caffeinate -i` (a closed lid still sleeps it). When a session disappears, the supervisor checks the Drive log for this run's guard line. If the guard stopped the VM, it reports and does not restart.
