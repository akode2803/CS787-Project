The recipe: four changes to a frozen chat model

1

Bidirectional attention

The causal mask becomes a full mask in every layer, so prompt, answer and padding all see each other.

2

LoRA on Q and V only

Rank 1024, α 1024. Base, embeddings, head and norms stay frozen: adapters are 4.1–5.8% of parameters.

3

No label shift

The same LM head predicts the clean token at the same position. An existing token is the mask: MASK, or <?> for Ministral.

4

Masked-diffusion loss

Hide answer tokens at a random rate t and learn to fill them back in, LLaDA-style (next slide).

Source: BYOD §3.2 and Table 2. Mergeable after training: W ← W + (α/r)·BA (Appendix B).

The recipe changes four things. One: the causal mask becomes bidirectional in every layer. Two: the base stays frozen, and rank-1024 LoRA adapters go on the query and value projections only, about five percent of the parameters . Three: no next-token shift. Each position predicts its own clean token, and an existing token serves as the mask.
